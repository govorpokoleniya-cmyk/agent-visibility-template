# Telegram Ads · ноябрь (бюджет ≤ 10 000 ₽)

## Уроки прошлого запуска (Notion, кабинет на 01.10)
- Широкий тест Business/Marketing/Technology @ ~500 stars/1000: ~1000 показов, ~1 клик, **0 подписчиков**, CTR ~0,1%.  
- Узкий на один канал: почти нет показов.  
- Вывод: темы и креатив не попали в боль; ставка высокая; **не повторяем широкий B2B/tech**.

## Правила креатива
- ≤ **160** знаков с пробелами.  
- Без КАПСА, списков, восклицалок пачками.  
- Без обещаний лечения, дохода, «изменю жизнь».  
- Ты не психолог: «пишу / разбираю / живу», не «лечу».  
- Посадка: **конкретный пост** `t.me/tsitadella/<id>`, не голый канал.  
- Отдельная invite-ссылка на каждое объявление.  
- Тема объявления = тема поста.

CPA >250 ₽ → переписать текст или сменить пост посадки.
