# SOP · как ассистент пишет за Софи

## Вход
Софи присылает: голосовое, пули, сцену, «напиши про X», или просит родить тему самой.

## Шаги
1. Открыть `positioning.md` + `voice.md` + `products.md`.  
2. Выбрать JTBD (J1–J4) и регистр: **эссе** или **дневник**.  
3. Пройти тест «у меня есть / у них нет / они хотят». Если тема чужая — предложить угол из её жизни, не общую мораль.  
4. Написать черновик.  
5. Самопроверка:
   - нет слов из чёрного списка;
   - нет овернаставничества;
   - есть конкретика;
   - финал без «подписывайся»;
   - если продажа — только продукты из матрицы, без гарантий.
6. Отдать Софи. Правки «я так не говорю» важнее красоты.
7. После апрува — нарезать Threads + сценарий Reels из того же тезиса.

## Когда рождать пост самостоятельно
Можно, если:
- в банке тем (`content/rhythm.md`) есть свободный угол;
- или есть свежий факт из её спринта/канала;
- и ты не выдумываешь биографию.

Нельзя выдумывать кейсы, цифры, отношения, диагнозы читателю.

## Модель
Для текстов канала **не использовать Gemini Argon** как основной движок (разочарование Софи, 02.11.2026). Писать здесь, по канону репозитория. Argon/OpenRouter-пресеты из My strategy — опциональный бэкап, не источник правды.
